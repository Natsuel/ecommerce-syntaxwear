## Sobre o Projeto

<p>SyntaXWear é um site de e-commerce moderno desenvolvido com HTML5 e CSS3, focado em apresentar uma coleção de calçados com design responsivo e uma experiência de usuário intuitiva.</p>

---

## ⭐ Funcionalidades

- ✅ Design responsivo e moderno
- ✅ Página inicial com hero section
- ✅ Categorias de produtos
- ✅ Grid de produtos
- ✅ Header e footer personalizados
- ✅ Paleta de cores consistente com variáveis CSS
- ✅ Componentes reutilizáveis

---

## 📁 Estrutura de pastas

```
ecommerce-syntaxwear/
├── index.html              # Página principal
├── README.md               # Documentação
├── css/
│   ├── base.css           # Estilos básicos
│   ├── reset.css          # Reset CSS
│   ├── variables.css      # Variáveis de cores e fonts
│   └── components/
│       ├── footer.css     # Estilos do rodapé
│       ├── header.css     # Estilos do cabeçalho
│       ├── hero.css       # Estilos da seção hero
│       ├── product-category.css  # Estilos de categorias
│       └── product-grid.css      # Estilos do grid de produtos
└── images/
    ├── banners/           # Imagens de banners
    ├── cards/             # Imagens de cards
    ├── favicons/          # Ícones do site
    ├── icons/             # Ícones gerais
    ├── logo/              # Logo da marca
    └── products/          # Imagens dos produtos
```

---

## 🛠 Tecnologias utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização e layout

---

## 🚀 Como usar

1. Clone ou baixe o repositório
2. Abra o arquivo `index.html` em seu navegador
3. Navegue pela página e explore os produtos

Não há dependências externas ou instalação necessária!
